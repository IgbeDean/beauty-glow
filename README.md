# Beauty Glow

A modern, responsive web application built using the Flask framework. Beauty Glow is designed to provide a seamless user experience for exploring beauty products, tips, and skincare routines.

## 🚀 Features

- **Dynamic Routing:** Powered by Flask's robust routing controller architecture.
- **Responsive Layout:** Beautiful, modern UI optimized across mobile, tablet, and desktop viewports.
- **Clean Architecture:** Built with modular components making it highly scalable and easy to maintain.

## 🛠️ Built With

- **Backend Framework:** Python 3.14.3 & Flask
- **Frontend Layer:** HTML5, CSS3, JavaScript
- **Icons & Assets:** Font Awesome / Google Fonts
